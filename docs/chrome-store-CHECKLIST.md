## Order (do not skip)

| Step | Where | What |
|------|--------|------|
| 0 | **Deploy web** | `/privacy` must be live at `https://www.gigster.website/privacy` |
| 1 | **Privacy practices** | Privacy policy URL → `https://www.gigster.website/privacy` |
| 2 | **Privacy practices** | Paste all justifications from `chrome-store-privacy-paste.md` |
| 3 | **Privacy practices** | Check data usage certification box |
| 4 | **Account → Settings** | Add contact email + **verify** via inbox link |
| 5 | **Store listing** | Summary, description, icon, screenshot 1280×800 |
| 6 | **Distribution** | Public (or Unlisted) |
| 7 | **Save draft** → **Submit for review** |
